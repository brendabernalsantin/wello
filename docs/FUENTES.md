# Fuentes de configuración y recursos

Se consultó la documentación oficial de Supabase el 3 de noviembre de 2026 para configurar el proveedor Google, la URI de callback de Supabase, el retorno de la aplicación y el intercambio de código PKCE. La configuración no se aplicó a cuentas reales.

- [Sign in with Google — Supabase](https://supabase.com/docs/guides/auth/social-sign-in/auth-google)
- [PKCE flow — Supabase](https://supabase.com/docs/guides/auth/sessions/pkce-flow)

Los PNG Icons8 y las capturas/ilustraciones de inspiración fueron aportados por la usuaria. Los ZIP incluían cuatro ilustraciones de alimentos/cocina/meditación. Se reutilizaron los iconos pertinentes; seis caritas y la planta se recortaron de capturas aportadas, no se generaron caritas adicionales. [Icons8](https://icons8.com) se atribuye dentro de Mis datos. La ilustración de meditación y el recurso de fitness se aportaron como referencias; debe verificarse su licencia antes de distribuir públicamente o comercializar. Lucide aporta los iconos de controles bajo ISC.

La búsqueda de tiendas consulta OpenStreetMap mediante Overpass exclusivamente después de solicitar ubicación. Se probó una consulta real usando coordenadas públicas del centro de Ciudad de México, no la ubicación de la usuaria: el proveedor respondió HTTP 406. Por ello la búsqueda real queda no validada; el flujo manual y las respuestas simuladas siguen disponibles. No se almacenan coordenadas en compras.
